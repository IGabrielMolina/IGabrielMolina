## High-Impact Engineering Projects

### [Kitsu: Production-Ready RAG & Agentic Orchestrator](LINK_A_TU_REPO)
> **Engineering Focus:** Security, Observability, and Data Sovereignty.
- **The Solution:** A secure AI orchestration engine featuring Metadata-based RBAC and a Graceful Degradation logic to prevent hallucinations.
- **Key Architecture:** Implemented a real-time Telemetry & Audit Trail in PostgreSQL, capturing confidence scores and retrieval latency for every interaction.
- **Impact:** Eliminates external API costs and ensures **GDPR compliance** by keeping 100% of the data within the local infrastructure.
- **Security:** Deterministic security layer using Qdrant metadata filtering, ensuring users only access authorized information based on their cryptographic role.
- (Codenamed "Kitsu")

### [Enterprise Multi-Platform ETL Engine](https://github.com/IGabrielMolina/enterprise-social-etl.git)
> **Engineering Focus:** High-Availability & Data Consistency.
- **The Solution:** A high-performance pipeline synchronizing real-time metrics for 23 corporate accounts across TikTok, Meta, and YouTube.
- **Key Architecture:** Optimized JavaScript nodes for $O(1)$ deduplication and Atomic Consistency (Delete-before-Write) to guarantee 100% data integrity in PostgreSQL.
- **Impact:** Automated 16+ hours/week of manual gathering with a self-healing architecture that manages OAuth2 refreshes and API rate-limits autonomously.
